# 布瑞哌唑 (Brexpiprazole / 敏达妥® / Rexulti)

## 📋 药物机制概览与临床定位
【药物分类】新一代 5-HT-DA 活性调节剂 (SDAM)。
【药理机制】D2 部分激动（内在活性较阿立哌唑更低，静坐不能风险极低）+ 强效 5-HT1A 部分激动 + 5-HT2A 拮抗。
【适应症】精神分裂症及难治性抑郁障碍 (TRD) 一线增效。
【临床优势】改善抑郁心境与认知，极少发生镇静、催乳素升高与 EPS。
