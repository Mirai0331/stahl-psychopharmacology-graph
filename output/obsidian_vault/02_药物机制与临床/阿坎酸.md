# 阿坎酸 (Acamprosate / 坎普拉® / Campral)

## 📋 药物机制概览与临床定位
【药物分类】NMDA / GABA 神经传递平衡调节剂。
【药理机制】抑制慢性酒精戒断引起的高谷氨酸兴奋毒性，增强 GABA 抑制。
【适应症】酒精依赖完全戒断后的长期维持治疗。
【临床优势】帮助维持长期戒酒状态，完全不经肝脏代谢（肾排泄），肝功能受损者安全。
