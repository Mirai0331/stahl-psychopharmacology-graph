# 伏硫西汀 (Vortioxetine / 心达悦® / Brintellix)

## 📋 药物机制概览与临床定位
【药物分类】5-HT 多模式调节剂 (SMS)。
【药理机制】抑制 SERT + 全激动 5-HT1A + 部分激动 5-HT1B/1D + 强拮抗 5-HT3 与 5-HT7。
【适应症】抑郁障碍（尤其伴认知损害、工作记忆减退者）。
【临床优势】直接增强海马 LTP 长时程增强与突触再生，显著改善抑郁相关执行功能损害。
